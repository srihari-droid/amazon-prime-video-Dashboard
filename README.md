# Amazon Prime Video Data Analysis Dashboard

## 📊 Project Overview

This project is an interactive data analysis dashboard created using Microsoft Power BI.

The dashboard analyzes Amazon Prime Video movies and TV shows and provides insights into titles, ratings, genres, directors, countries, and release years.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## 📌 Dashboard Features

- Total number of titles
- Total ratings
- Total genres
- Total directors
- Top countries
- Rating distribution
- Genre analysis
- Movies vs TV shows
- Titles by year
- Country-wise analysis
